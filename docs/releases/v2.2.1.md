# PikachuNovel v2.2.1

本版本把 Antigravity 的首次启动和重新登录入口接入小说工作台，并修复浏览器能访问 Google、`agy` 却在令牌交换阶段直连超时的问题。

## 新增与修复

- **应用内启动与登录**：Antigravity 模型配置组新增“启动/登录 agy”，可从 PikachuNovel 直接打开独立交互终端，完成首次配置、Google 登录或重新认证。
- **系统代理衔接**：Windows 自动读取系统代理，macOS/Linux 沿用可用的系统或进程代理；同一代理环境同时用于交互登录与受控 Headless 写作调用。
- **凭据边界保持不变**：PikachuNovel 不读取或保存 Google 登录令牌，也不会把 Gemini API Key 传给账号登录模式；启动命令不经过 shell 拼接。
- **可操作错误提示**：登录失效或调用失败时，界面会引导用户回到设置页启动 `agy`、恢复调度并继续原任务。

## 使用说明

1. 在模型设置中把需要的任务组切换为“Antigravity（Google 登录）”。
2. 点击“检测安装”，再点击“启动/登录 agy”。
3. 在新终端完成初始化与 Google 登录，回到设置页点击“测试连接（使用额度）”。
4. 保存配置；若调度此前因认证错误暂停，点击“恢复调度”后继续原写作任务。

Windows 用户下载 `PikachuNovel.exe`，同页的 `PikachuNovel.exe.sha256` 用于校验和应用内更新。本版本不捆绑 `agy`，仍需先安装官方 Antigravity CLI。

完整回归通过：268 项 Python 测试、45 个子测试和 32 项前端测试。Windows 独立 EXE 已重新构建，并核验打包资源包含 Antigravity 登录入口和系统代理提示。本轮未调用真实 Google 账号或消耗模型额度。
