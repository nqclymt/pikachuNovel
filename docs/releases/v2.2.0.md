# PikachuNovel v2.2.0

本版本增加可选的 Antigravity CLI 后端，并修复写作规范丢失、跨卷承接和中断后重复生成等问题。

## 新增与修复

- **Antigravity CLI 接入（实验性）**：四类模型角色可以独立选择 API 或官方 `agy` CLI；提供安装检测、连接测试、共享请求队列、取消及登录／额度异常暂停。CLI 需自行安装，由 CLI 管理 Google 登录，程序不读取或保存 Google 登录凭据。
- **统一写作要求**：默认规范纳入 Windows、Mac 和 Python 构建；本轮要求优先于持久规范和参考文风，规划、正文、精修与验收共享要求。
- **跨卷承接与动态记忆**：跨卷查找前章正文和系统面板；缺少前章面板时明确报错。人物所知、关系、物品、伤势、承诺和伏笔从已保存正文增量提取，保留来源与证据，修改或删除旧章后重算受影响记忆。
- **按阶段恢复**：保存规划、初稿、精修、事实审查和内容验收检查点；恢复原任务参数与任务标识，避免额度中断后重复生成初稿，或误跳过尚未处理的精修章节。
- **事实纠错与章节验收**：拒绝重复定位、无事实依据或超范围替换；纠错后再次审查。明确剧情错误会保留候选稿与报告并停止后续章节，允许人工修改候选稿后继续验收。
- **同书调度与保护**：章纲和正文共用队列与跨进程书锁；前章缺失时阻止后章写作，运行中的内容编辑、重置和删除会被阻止。不同作品可并行。
- **参考文风检索**：增加最低相关性要求，没有合适案例时使用作者画像。另修复 Windows 换行反复转换导致空行增加及检查点不匹配的问题。

## 使用说明

- Windows 用户下载 `PikachuNovel.exe`；同页 `PikachuNovel.exe.sha256` 用于完整性校验及应用内更新。已有作品和配置无需迁移。
- 使用 Antigravity 前请自行安装官方 CLI、完成 Google 登录，再在“模型配置”中检测和测试连接。实际可用模型和额度以 CLI 与账号状态为准；本轮尚未使用已登录真实账号验证长篇生成。
- 内容验收会增加模型调用，即使关闭精修也会执行。旧作品首次续写需要补建历史记忆，旧章修改后可能重算后续记忆，因此调用量和等待时间会增加。
- 候选稿位于 `file_system/drafts/vol_XX/candidates/`，验收报告位于同级 `acceptance/`。结束任务后可编辑候选稿，再继续任务重新审查。
- 本次提供 Windows 可执行文件。Mac arm64 构建配置和资源修复随源码提供，本次没有构建或验证 Mac 安装包。

## 验证

写作流程完整回归通过：263 项 Python 测试、45 个子测试和 31 项前端测试。隔离测试包通过源码模块、提示词和默认规范归档核验，以及启动、配置和子进程中文日志检查。上述测试未调用真实模型；文学质量、记忆提取和语义验收仍需结合实际作品核对。
