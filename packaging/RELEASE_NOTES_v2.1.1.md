# PikachuNovel v2.1.1

本版改进正文写作与自然化精修流程，减少章纲说明混入正文、背景设定反复解释，以及无差别改写造成的事实漂移。

## 正文与精修

- 章纲和场景计划区分本章必须发生的事件与背景约束，写作时遵守角色知情范围，避免把规划标签直接写进正文。
- 自然化精修改为“问题审阅 → 局部修改 → 修改验证”。审阅必须引用原文，只替换可定位的问题片段，并限制修改范围。
- 检查人物事实、数量、篇幅变化和修改效果；验证未通过或模型调用失败时保留对应原文，涉及剧情规划的问题只记录建议。
- 保留精修前正文，并保存审阅、修改和验证记录，便于查看改了哪里、哪些问题没有处理。

自然化精修每章通常增加 1–3 次模型调用。效果仍取决于正文、参考样本和模型；本次没有进行真实模型的创作质量或 AI 检测分数对比，不承诺检测通过率。

## Mac 构建准备

- 增加 M 系列 Mac 的 arm64 打包脚本、GitHub Actions 配置和冒烟验证脚本。
- 补充 Finder 定位章节支持，调整 Mac 默认小说目录及启动错误日志位置。
- 本次只发布 Windows 安装包。Mac 安装包尚未构建和真机验证。

## 验证

- 本地自动化测试：108 项测试及 31 个子测试通过。
- Windows 安装包发布前检查内置模块与提示词，并验证本地服务、页面资源、后台工作区创建及中文日志。
