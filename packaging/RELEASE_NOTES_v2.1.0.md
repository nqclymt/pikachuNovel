# PikachuNovel v2.1.0

## 文风与正文生成

- 新增 Style Engine v2：按场景拆分参考正文，建立多维元数据并检索匹配的连续原文样本。
- 新增参考文风画像、场景写作计划和段落自然化流程，针对异常段落局部处理，避免整章无差别重写。
- 新增人化样本库与降级策略；模型分析失败时仍可使用已建立的原文样本和统计画像。
- 加强写作上下文预算、引用去重、取消传播和章节原子写入，失败时保留原正文。

## 参考拆解与工作流

- 支持复用已完成的参考拆解结果，并可只清除派生分析、保留参考源文件。
- 改进智能分卷和卷纲生成断点，失败后可从已保存边界与卷纲继续。
- 新增工作流预设及浏览器端预设校验，便于切换不同创作流程。
- 优化机制决策上下文，限制长度同时保留核心设定。

## 桌面与文件操作

- 新增章节文件定位、打开和相关安全校验。
- 更新 Windows 构建与成品验证脚本，确保新增静态资源和功能被打包。
