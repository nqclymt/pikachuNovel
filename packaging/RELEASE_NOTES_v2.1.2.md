# PikachuNovel v2.1.2

修复故事情节单元被清空后，章纲和正文仍能展示但无法删除的问题。

- 删除章纲或正文时，优先使用情节文件中的章节范围；情节缺失时，从已保存的产物记录恢复归属。
- 无法恢复归属的内容显示为“未归属章节”，可单独选择和删除。缺失情节的保留批次仍可查看、删除，继续生成前需恢复故事情节。
- 修复章纲重置只清空对话却保留文件的情况，删除后刷新批次选择和内容列表。
- 删除正文时一并清理对应的原稿、历史版本、精修记录和最终版标记；章纲和正文的删除操作保持独立。
- 按实际记录的章节集合处理非连续章节，避免删除同卷其他批次或其他卷的内容。

本次修复不自动清理既有小说文件，用户仍需在界面中选择并确认删除。
